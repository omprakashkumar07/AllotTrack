# AllotTrack

A full-stack application built with Next.js 14, Express, and Prisma for tracking Initial Public Offerings (IPOs) and managing applicants' funds and allotments.

## Tech Stack
- **Frontend**: Next.js 14 App Router, TypeScript, Tailwind CSS, Recharts
- **Backend**: Node.js, Express, TypeScript, Prisma ORM
- **Database**: PostgreSQL

---

## Deployment Guide

This guide covers deploying the PostgreSQL database on Neon, the backend on Render, and the frontend on Vercel.

### Step 1: Push to GitHub
1. Create a new repository on GitHub.
2. Initialize git in the root folder, commit, and push. (Our `.gitignore` is correctly configured to ensure `.env` files are never committed).
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/yourusername/your-repo-name.git
   git push -u origin main
   ```

### Step 2: Database Setup (Neon Postgres)
1. Go to [Neon.tech](https://neon.tech/) and create a new project.
2. Copy the PostgreSQL connection string.
3. Locally, inside the `/backend` folder, temporarily set the `DATABASE_URL` in your `.env` to this new Neon connection string.
4. Run migrations against the production database to create the schema:
   ```bash
   cd backend
   npx prisma migrate deploy
   ```

### Step 3: Deploy Backend (Render)
1. Go to [Render.com](https://render.com/) and create a new **Web Service**.
2. Connect your GitHub repository and set the Root Directory to `backend`.
3. Render will automatically detect the `render.yaml` configuration in the backend folder.
4. Provide the following Environment Variables in the Render dashboard:
   - `DATABASE_URL`: Your Neon Postgres connection string.
   - `PAN_ENCRYPTION_KEY`: A 32-character secure random string (e.g. `your-32-char-secure-secret-key!`).
   - `GEMINI_API_KEY`: Your Google Gemini API Key for live IPO fetching.
   - `ADMIN_EMAIL`: The login email for the dashboard.
   - `ADMIN_PASSWORD`: The login password.
   - *Note: `JWT_SECRET` is automatically generated by Render per our `render.yaml`.*
5. Deploy! Once finished, copy the public URL (e.g., `https://ipo-tracking-backend.onrender.com`).

### Step 4: Deploy Frontend (Vercel)
1. Go to [Vercel.com](https://vercel.com/) and import your GitHub repository.
2. Edit the Project Settings during import:
   - **Framework Preset**: Next.js
   - **Root Directory**: `frontend`
3. Expand **Environment Variables** and add:
   - `NEXT_PUBLIC_API_URL`: Set this to your Render backend URL followed by `/api` (e.g., `https://ipo-tracking-backend.onrender.com/api`).
4. Click **Deploy**. Vercel will build and host your Next.js application!

## Local Development Setup

1. **Backend**:
   - `cd backend`
   - `npm install`
   - Setup your `.env` (DATABASE_URL, JWT_SECRET, PAN_ENCRYPTION_KEY, GEMINI_API_KEY)
   - `npx prisma db push`
   - `npm run dev`

2. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev` (Runs on http://localhost:3000)
